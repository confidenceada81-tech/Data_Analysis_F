USING BASIC DATA ANALYSESING TOOLS FOR BEGINNERS

`Overview`

This repository documents my learning journey in Data Analysis through the ALX Data Analytics Programme. It contains beginner-friendly projects, exercises, datasets, and dashboards created while learning the foundations of data analysis.

`The repository is divided into three major sections:`

- Spreadsheet Analysis (Google Sheets / Microsoft Excel)
- SQL for Data Cleaning and Data Extraction
- Data Visualization with Power BI

The `goal` of this repository is to showcase my growth, practical projects, and understanding of core data analysis concepts.

1. Spreadsheet Analysis

   This section contains SQL scripts and exercises focused on:

       Dashboard creation
